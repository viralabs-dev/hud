# Gate de terminal Windows do HUD Rust

[English](roteiro-windows.en.md)

Ainda não há aceite nativo Rust Windows. Não executar pacote/helper PDCurses histórico como se fosse Rust; [matriz](../rust/docs/support.pt-BR.md) separa bibliotecas/políticas de backend validado.

Após build/installer/storage/process-tree/ConPTY autorizados e validados nativamente, definir checklist Windows Terminal/conhost por versão: foco/mouse/drop/cancel, Unicode/OEM, dimensões/resize, permissões/paths/ACL/reparse, shutdown/filhos e restauração. Registrar artefato/OS/arquitetura e resultados reais. Esta página não autoriza instalar ferramentas nem executar teste real pendente.

[Roteiro Python histórico](legacy/roteiro-windows.pt-BR.md) conserva PDCurses e contratos legados. Emulação x64 não prova Windows ARM nativo.
